# press-enter-app

TypeScript + React (Vite)

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 이 자동으로 열립니다.
시작 화면에서 **Enter**(또는 클릭) → 메인 화면으로 이동합니다.

## 구조

```
src/
  App.tsx              화면 전환 (start ↔ main)
  pages/StartPage.tsx  "PRESS ENTER" 시작(로그인) 화면
  pages/MainPage.tsx   메인 화면
  index.css            스타일
```
